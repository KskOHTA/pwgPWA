# pwgPWA

元の [pwg](https://github.com/KskOHTA/pwg) をPWA化した、再現可能なパスワードジェネレーターです。

## 概要

- ホーム画面への追加に対応
- オフラインで利用可能
- 入力内容はブラウザー内で処理し、保存・送信しません
- HTTPSまたはlocalhostで動作

## GitHub Pages

リポジトリ設定の **Pages** で、Sourceを`Deploy from a branch`、Branchを`main` / `/ (root)`に設定してください。
公開URLは `https://KskOHTA.github.io/pwgPWA/` です。
